# B Yekan / Yekan webfont

Self-hosted Persian webfont from [sayjeyhi/typeface-yekan](https://github.com/sayjeyhi/typeface-yekan).

- Font: `dist/Yekan.woff2` from the source repository, downloaded October 18, 2026.
- License: SIL Open Font License 1.1; the complete upstream notice and license are included in `LICENSE.txt`.
- The binary is unmodified. `B Yekan` is the application's CSS font-family alias.

The global font face is limited to Arabic/Persian Unicode ranges, including Persian digits and joining controls. Persian text uses this font in pages, tables, forms, menus, and dialogs; Latin text uses the existing Arial/Helvetica stack. The font uses `font-display: swap` and is served by this application, without runtime requests to a font CDN.
